# Dotfiles

Personal configuration files across different environments and tools.

## Structure

* **[`nvim/`](./nvim)**: Personal [Neovim](https://neovim.io) setup based on [LazyVim](https://github.com/LazyVim/LazyVim).
* **[`windows/`](./windows)**: Configurations for Windows desktop workflow:
  * **[GlazeWM](./windows/glzr)**: Tiling window manager configuration.
  * **[WezTerm](./windows/wezterm)**: GPU-accelerated terminal emulator settings.
* **[`oh-my-posh/`](./oh-my-posh)**: Custom theme (`azure-amro.json`) for [Oh My Posh](https://ohmyposh.dev) with Azure CLI and PowerShell context.
